# FLORA Creative ROI Dashboard

A live interactive GTM tool built to demonstrate what an AI-native GTM & Operations hire brings to FLORA.

## Deploy to Vercel (2 minutes)

1. Push this repo to GitHub
2. Go to vercel.com → New Project → Import your repo
3. Zero config needed — hit Deploy
4. Share the live URL

## What it does

- Interactive sliders: team size, hourly rate, hours/week, % repetitive tasks
- Live metrics: hours saved, annual labour saving, output multiplier, toolstack cost saving
- Cost breakdown: before/after bar charts
- Adoption funnel: ICP → partner pipeline view
- GTM roadmap: 12-week 0→1 launch plan specific to FLORA
- AI-native ops stack: how the role runs on automation-first principles
